# poi 中破・大破演出マスク

[English](README.md) | [简体中文](README.zh-CN.md) | [正體中文](README.zh-TW.md) | [日本語](README.ja-JP.md) | [한국어](README.ko-KR.md)

**poi 12.0.1** 向けの艦これ用プラグインです。中破・大破カットイン中にゲーム画面全体を不透明なマスクで覆い、演出終了後に自動で元の画面に戻します。マスク中も演出と音声は再生されます。

## インストール

poi のプラグイン管理画面で、次のパッケージ名を入力してインストールしてください。

```text
poi-plugin-damage-shield
```

インストール後、プラグインを有効にしてください。一覧に表示されない場合は poi を再起動してください。

## 使い方

1. 「中破・大破演出マスク」を開き、「自動マスクの準備完了」と表示されるまで待ちます。その後、中破・大破演出が自動でマスクされます。
2. 「マスクをテスト（3秒）」で効果を確認できます。ゲーム画面の読み込み中は、このボタンは使用できません。
3. 「自動マスクを一時停止」または「自動マスクを有効化」で切り替えられます。設定は保存されます。
4. 「マスクの色」で選んだ色はすぐに反映され、自動で保存されます。「既定の色に戻す」で既定の暗い色に戻せます。

## 言語

poi の言語設定に従い、簡体字中国語、繁体字中国語、日本語、英語、韓国語に対応しています。

## 注意事項

- ゲーム画面のみを覆います。poi のパネルやデスクトップはそのまま表示されます。
- 母港で常時表示される損傷イラストや、損傷以外の演出は対象外です。
- ゲーム更新後はプラグインの更新が必要になる場合があります。不具合は [Issues](https://github.com/asparagusThief/poi-plugin-damage-shield/issues) に、poi のバージョン、プラグインのバージョン、プラグイン画面の状態表示を添えてご報告ください。
