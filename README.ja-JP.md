# poi 中破・大破演出マスク

[English](README.md) | [简体中文](README.zh-CN.md) | [正體中文](README.zh-TW.md) | [日本語](README.ja-JP.md) | [한국어](README.ko-KR.md)

**poi 12.0.1** 向けの艦隊これくしょん用プラグインです。中破・大破のカットイン演出中に、ゲーム画面全体を不透明な黒いマスクで覆います。演出と最後の白いフェードが消えると、自動で元の画面に戻ります。マスク中もゲームの演出と音声は再生されます。

自動テストおよび実際の PIXI Canvas／WebGL レンダラーによるピクセル検証を実施済みです。**poi 12.0.1 のオンライン戦闘で自動的に作動することも、ユーザーにより確認されています**。

## インストール

### パッケージ名からインストール

poi のプラグイン管理画面を開き、インストール欄に次のパッケージ名を入力してインストールします。

```text
poi-plugin-damage-shield
```

インストール後、プラグインを有効にしてください。すぐに表示されない場合は poi を再起動し、一覧から「中破・大破演出マスク」を探してください。poi に同梱されている React と翻訳ライブラリを使用するため、追加の実行時依存パッケージやビルド作業は不要です。

### ソースまたはローカルパッケージからインストール

ソースディレクトリで次のコマンドを実行すると、現在の Windows ユーザーの poi データディレクトリにインストールされます。

```powershell
& .\scripts\install-local.ps1
```

スクリプトは `%APPDATA%\poi\plugins-extra\node_modules\poi-plugin-damage-shield` を作成し、プラグイン本体、翻訳、各言語の README をコピーします。インストール先がすでに存在する場合は、上書きを避けるため停止します。完了後、poi を再起動してください。

または、`npm.cmd run pack:local` で生成した `.tgz` ファイルを poi のローカルパッケージインストール機能で読み込めます。いずれかの方法を選んでください。

## 使い方

1. 「中破・大破演出マスク」のプラグイン画面を開きます。ゲームの準備ができるまでは読み込み状況が表示され、自動でゲーム画面に接続します。
2. 「自動マスクの準備完了」と表示されると、中破・大破演出が自動でマスクされます。
3. 「マスクをテスト（3秒）」で効果を確認できます。最初のゲーム画面が描画されるまでは、このボタンは無効です。
4. カットイン演出と最後のフェードが終了すると、ゲーム画面が自動で戻ります。プラグイン画面には、今回のゲーム読み込み以降に検出した演出の回数が表示されます。

自動マスクは初期設定で有効です。「自動マスクを一時停止」で一時的に無効にでき、設定は保存されます。「自動マスクを有効化」で再開できます。プラグインを無効化またはアンインストールすると、マスクとプラグイン自身の描画フックが取り除かれます。

起動時は DMM ページ全体や他の子フレームの読み込み完了を待たず、準備のできたゲームフレームに接続します。待機中は 250 ミリ秒ごとに確認し、ゲーム画面の参照や読み込み状態が変わるとすぐに再試行します。準備完了後は毎秒状態を更新します。ゲームエンジンと最初のゲーム画面自体の読み込みは必要です。

## 言語

インターフェースは poi の言語設定に従い、簡体字中国語、繁体字中国語、日本語、英語、韓国語に対応しています。プラグイン名、説明、ボタン、状態表示、マスク内の文字が翻訳されるため、プラグイン側で言語を選ぶ必要はありません。

poi の言語を切り替えると、現在の状態表示と表示中のマスクもすぐに更新されます。翻訳ファイルが追加される更新をインストールした際は、プラグインの再読み込みまたは poi の再起動を行ってください。インターフェースの翻訳は `i18n/` にあり、未翻訳の項目には英語の既定テキストを使用します。README の言語は、このページ上部のリンクで切り替えられます。

## 対象範囲

- ゲーム画面全体を覆います。poi のプラグインパネルや OS のデスクトップは覆いません。
- 戦闘 API から再生時間を推測せず、ゲームの Canvas 描画内容から演出の開始と終了を判定します。
- ゲーム本来の描画と音声は継続します。出力キャンバスに不透明な描画を追加し、ゲームページを覆います。
- 同じ演出構造を使う敵の特殊な損傷カットインも対象です。
- 母港で常時表示される中破・大破イラストや、損傷以外の演出は対象外です。
- poi の現在のゲーム webview 参照を使い、ページ更新後やゲーム別ウィンドウへの切り替え後に再接続します。ホスト側の切り替えロジックはテスト済みですが、実際の poi 上でのウィンドウ切り替えは実機確認が必要です。

## 検出方法と制限

検出は、公開されている艦これクライアント **6.3.6.0** の解析に含まれる `TaskDamageCutin`／`TaskEnemyDamageCutin` のコンテナ構造と、`battle_cutin_damage_100` テクスチャを基にしています。ゲームページのメイン JavaScript 実行環境で描画を監視し、描画前に損傷演出を判定します。元の描画が完了してから同じ JavaScript 呼び出しが終了するまでの間にキャンバスを覆うため、Canvas から直接取得するスクリーンショットもマスクされます。最後の白いフェードは実際のシーンオブジェクトの有無を追跡し、固定の演出時間には依存しません。

ゲームの更新でコンテナのフィールド、テクスチャ名、描画エンジンが変更された場合は、対応の更新が必要になることがあります。「自動マスクの準備完了」は、現在のゲーム画面で検出処理が動作していることを示します。不具合を報告する際は、poi のバージョン、ゲームのバージョン、プラグインの状態表示、ゲーム別ウィンドウを使用していたかを添えてください。

poi のインストールファイルやゲームスクリプトファイルは変更しません。ゲームへのリクエスト送信、ゲーム操作、アカウント情報のアップロードも行いません。

## 開発とチェック

開発用のチェックには Node.js 20 以降が必要です。

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run check
npm.cmd test
New-Item -ItemType Directory -Path dist -Force
npm.cmd run pack:local
```

`index.js` は poi プラグインのエントリーポイント、`src/controller.js` は webview とライフサイクル管理、`src/game-shield.js` はシリアライズ可能なゲームページへの注入処理を担当します。`src/i18n.js` は poi の翻訳リソースとの接続と既定テキストを提供します。開発用依存パッケージの i18next はテスト専用で、実行時依存パッケージとしてはインストールされません。
