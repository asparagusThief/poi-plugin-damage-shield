# poi 중파·대파 연출 가리기

[English](README.md) | [简体中文](README.zh-CN.md) | [正體中文](README.zh-TW.md) | [日本語](README.ja-JP.md) | [한국어](README.ko-KR.md)

**poi 12.0.1**용 함대 컬렉션 플러그인입니다. 중파·대파 컷인 연출이 재생되는 동안 불투명한 검은 가림막으로 게임 화면 전체를 가립니다. 연출과 마지막 흰색 페이드가 사라지면 게임 화면을 자동으로 복원합니다. 화면을 가리는 동안에도 게임 연출과 소리는 계속 재생됩니다.

자동 테스트 및 실제 PIXI Canvas/WebGL 렌더러를 이용한 픽셀 검증을 통과했습니다. **poi 12.0.1의 온라인 전투에서 자동으로 작동하는 것도 사용자가 확인했습니다**.

## 설치

### 패키지 이름으로 설치

poi의 플러그인 관리 화면을 열고 설치 입력란에 다음 패키지 이름을 입력해 설치하세요.

```text
poi-plugin-damage-shield
```

설치 후 플러그인을 활성화하세요. 바로 표시되지 않으면 poi를 다시 시작한 뒤 플러그인 목록에서 「중파·대파 연출 가리기」를 찾으세요. poi에 포함된 React와 번역 라이브러리를 사용하므로 실행에 필요한 추가 패키지 설치나 빌드 과정은 없습니다.

### 소스 또는 로컬 패키지로 설치

소스 디렉터리에서 다음 명령을 실행하면 현재 Windows 사용자의 poi 데이터 디렉터리에 설치됩니다.

```powershell
& .\scripts\install-local.ps1
```

스크립트는 `%APPDATA%\poi\plugins-extra\node_modules\poi-plugin-damage-shield`를 만들고 플러그인, 번역 파일, 모든 언어의 README를 복사합니다. 대상 경로가 이미 있으면 기존 설치를 덮어쓰지 않도록 중단합니다. 설치 후 poi를 다시 시작하세요.

또는 `npm.cmd run pack:local`로 만든 `.tgz` 파일을 poi의 로컬 패키지 설치 기능으로 설치할 수 있습니다. 한 가지 설치 방법을 선택하세요.

## 사용 방법

1. 「중파·대파 연출 가리기」 플러그인 화면을 엽니다. 게임이 준비되기 전에는 로딩 상태가 표시되며, 플러그인이 게임 화면에 자동으로 연결합니다.
2. 「자동 가리기 준비 완료」가 표시되면 중파·대파 컷인 연출을 자동으로 가립니다.
3. 「가림막 테스트 (3초)」를 눌러 효과를 미리 볼 수 있습니다. 첫 게임 화면이 준비되기 전에는 테스트 버튼이 비활성화됩니다.
4. 컷인 연출과 마지막 페이드가 끝나면 게임 화면이 자동으로 복원됩니다. 플러그인 화면에는 이번 게임 로딩 이후 감지한 연출 횟수가 표시됩니다.

자동 가리기는 기본으로 켜져 있습니다. 「자동 가리기 일시 중지」를 누르면 잠시 끌 수 있으며 설정이 저장됩니다. 「자동 가리기 켜기」로 다시 활성화할 수 있습니다. 플러그인을 비활성화하거나 제거하면 가림막과 플러그인 자체의 렌더링 후크가 제거됩니다.

시작할 때 DMM 페이지 전체와 다른 하위 프레임의 로딩이 끝날 때까지 기다리지 않고 준비된 게임 프레임에 연결합니다. 대기 중에는 250밀리초마다 확인하며, 게임 화면 참조나 로딩 상태가 바뀌면 즉시 다시 시도합니다. 준비된 후에는 1초마다 상태를 갱신합니다. 게임 엔진과 첫 게임 화면 자체의 로딩은 완료되어야 합니다.

## 언어

인터페이스는 poi의 언어 설정을 따르며 중국어 간체, 중국어 번체, 일본어, 영어, 한국어를 지원합니다. 플러그인 이름, 설명, 버튼, 상태 메시지, 가림막 안의 글자가 번역되므로 플러그인에서 언어를 따로 선택할 필요가 없습니다.

poi의 언어를 바꾸면 현재 상태 메시지와 표시 중인 가림막의 글자도 즉시 갱신됩니다. 번역 파일이 추가되는 업데이트를 설치한 경우 플러그인을 다시 불러오거나 poi를 다시 시작하세요. 인터페이스 번역은 `i18n/`에 있으며 누락된 번역에는 기본 영어 문구가 사용됩니다. README 언어는 이 문서 상단의 링크로 선택할 수 있습니다.

## 적용 범위

- 게임 화면 전체를 가리며 poi의 플러그인 패널이나 운영체제 바탕 화면은 가리지 않습니다.
- 전투 API로 재생 시간을 추정하지 않고 게임의 Canvas 렌더링 내용으로 연출의 시작과 끝을 판단합니다.
- 원래 게임 렌더링과 소리는 계속 재생됩니다. 출력 캔버스에 불투명한 레이어를 추가하고 게임 페이지를 덮습니다.
- 같은 연출 구조를 사용하는 적의 특수 손상 컷인도 가립니다.
- 모항에서 계속 표시되는 중파·대파 일러스트나 손상과 무관한 연출은 가리지 않습니다.
- poi의 현재 게임 webview 참조를 통해 새로고침한 페이지나 별도 게임 창에 다시 연결합니다. 호스트 측 창 전환 로직은 테스트했으며, 실제 poi에서의 창 전환은 사용자 확인이 더 필요합니다.

## 감지 방식과 제한 사항

감지는 공개된 함대 컬렉션 클라이언트 **6.3.6.0** 분석에 있는 `TaskDamageCutin` / `TaskEnemyDamageCutin` 컨테이너 구조와 `battle_cutin_damage_100` 텍스처를 기반으로 합니다. 게임 페이지의 기본 JavaScript 실행 환경에서 렌더링을 감시하여 그리기 전에 손상 연출을 감지합니다. 원래 렌더링이 끝난 뒤 동일한 JavaScript 호출이 종료되기 전에 캔버스를 덮으므로, Canvas에서 직접 얻는 스크린샷에도 가림막이 적용됩니다. 마지막 흰색 페이드는 실제 장면 객체의 존재 여부를 추적하며 고정된 연출 시간을 사용하지 않습니다.

게임 업데이트로 컨테이너 필드, 텍스처 이름, 렌더링 엔진이 바뀌면 호환성 업데이트가 필요할 수 있습니다. 「자동 가리기 준비 완료」는 현재 게임 화면에서 감지가 실행 중이라는 뜻입니다. 문제를 보고할 때는 poi 버전, 게임 버전, 플러그인 상태 메시지, 별도 게임 창 사용 여부를 알려 주세요.

플러그인은 poi 설치 파일이나 게임 스크립트 파일을 수정하지 않으며, 게임 요청 전송, 게임 조작, 계정 정보 업로드를 수행하지 않습니다.

## 개발 및 검사

개발 검사를 실행하려면 Node.js 20 이상이 필요합니다.

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run check
npm.cmd test
New-Item -ItemType Directory -Path dist -Force
npm.cmd run pack:local
```

`index.js`는 poi 플러그인 진입점이며, `src/controller.js`는 webview와 수명 주기를 관리합니다. `src/game-shield.js`는 직렬화 가능한 게임 페이지 주입 로직을 포함하고, `src/i18n.js`는 poi 번역 리소스에 연결하고 기본 문구를 제공합니다. 개발 의존성인 i18next는 테스트에만 사용되며 실행 의존성으로 설치되지 않습니다.
