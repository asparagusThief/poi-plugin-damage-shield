# poi 중파·대파 연출 가리기

[English](README.md) | [简体中文](README.zh-CN.md) | [正體中文](README.zh-TW.md) | [日本語](README.ja-JP.md) | [한국어](README.ko-KR.md)

**poi 12.0.1**용 함대 컬렉션 플러그인입니다. 중파·대파 컷인 연출 중 게임 화면 전체를 검은 가림막으로 가리고, 연출이 끝나면 화면을 자동으로 복원합니다. 화면을 가리는 동안에도 연출과 소리는 계속 재생됩니다.

## 설치

poi의 플러그인 관리 화면에서 다음 패키지 이름을 입력해 설치하세요.

```text
poi-plugin-damage-shield
```

설치 후 플러그인을 활성화하세요. 목록에 표시되지 않으면 poi를 다시 시작하세요.

## 사용 방법

1. 「중파·대파 연출 가리기」를 열고 「자동 가리기 준비 완료」가 표시될 때까지 기다리세요. 이후 중파·대파 연출을 자동으로 가립니다.
2. 「가림막 테스트 (3초)」로 효과를 미리 볼 수 있습니다. 게임 화면 로딩 중에는 테스트 버튼을 사용할 수 없습니다.
3. 「자동 가리기 일시 중지」 또는 「자동 가리기 켜기」로 자동 가리기를 제어할 수 있습니다. 설정은 저장됩니다.

## 언어

poi의 언어 설정을 따르며 중국어 간체, 중국어 번체, 일본어, 영어, 한국어를 지원합니다.

## 참고 사항

- 게임 영역만 가리며 poi 패널과 바탕 화면은 그대로 표시됩니다.
- 모항에서 계속 표시되는 중파·대파 일러스트나 손상과 무관한 연출은 가리지 않습니다.
- 게임 업데이트 후에는 플러그인 업데이트가 필요할 수 있습니다. 문제가 있으면 [Issues](https://github.com/asparagusThief/poi-plugin-damage-shield/issues)에 poi 버전, 플러그인 버전, 플러그인 화면의 상태 메시지를 알려 주세요.
